# Berkontribusi ke SHYNTAX AUDIO

Terima kasih sudah tertarik membantu mengembangkan SHYNTAX AUDIO! Kontribusi berupa laporan bug, ide fitur, dokumentasi, pengujian, penerjemahan, dan kode sangat dihargai.

## Sebelum mulai
1. Baca README dan periksa Issues serta Pull Requests yang sudah ada.
2. Untuk perubahan besar, buka Issue atau Discussion terlebih dahulu agar arah pengerjaan disepakati.
3. Jangan mengunggah file musik, data pribadi, API key, password, token, keystore, atau file rahasia lainnya.

## Cara mengirim perubahan
1. Fork repository ini.
2. Buat branch dari `main`, misalnya `fix/library-scan` atau `feature/playlist`.
3. Kerjakan perubahan sekecil dan sefokus mungkin.
4. Pastikan proyek dapat dibangun dan jalankan pengujian yang relevan.
5. Jelaskan perubahan, alasan, cara pengujian, dan dampak kompatibilitas pada Pull Request.
6. Sertakan screenshot atau log yang sudah disensor jika perubahan menyentuh UI atau memperbaiki bug.

## Standar perubahan
- Utamakan stabilitas, privasi, aksesibilitas, dan kompatibilitas Android.
- Jangan menambahkan dependency tanpa alasan yang jelas.
- Hindari perubahan yang tidak terkait dalam satu Pull Request.
- Jangan menyertakan kredensial atau data pengguna dalam commit, log, maupun screenshot.
- Untuk perubahan audio, jelaskan perangkat, versi Android, format audio, dan langkah reproduksi jika relevan.

## Pengujian
Sertakan:
- Perangkat dan versi Android yang digunakan.
- Langkah untuk menguji perubahan.
- Hasil build/test yang dijalankan.
- Batasan atau pengujian yang belum dapat dilakukan.

## Review dan penggabungan
Semua Pull Request akan ditinjau oleh maintainer. Pengiriman Pull Request tidak menjamin perubahan akan langsung digabungkan. Maintainer dapat meminta revisi, pengujian tambahan, atau menolak perubahan yang tidak sesuai tujuan proyek.

Dengan berkontribusi, kamu setuju bahwa kontribusimu dapat didistribusikan di bawah lisensi proyek apabila/ketika lisensi proyek ditetapkan. Jika lisensi belum tersedia, tanyakan kepada maintainer sebelum mengirim kontribusi kode yang substansial.
