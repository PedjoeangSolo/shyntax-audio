# Kebijakan Keamanan

Jangan mempublikasikan kredensial, password, token, keystore, data pribadi, atau detail kerentanan yang belum diperbaiki pada Issues atau Discussions publik.

Untuk masalah keamanan, hubungi maintainer melalui kanal kontak yang tercantum pada profil GitHub PedjoeangSolo. Sertakan langkah reproduksi dan dampak yang dapat dibagikan dengan aman.

Jangan menguji keamanan pada perangkat, akun, atau layanan milik orang lain tanpa izin.
